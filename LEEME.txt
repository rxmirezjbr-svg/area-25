AREA 25 - como obtener el APK (en una computadora con Node.js y Android Studio)

1) Abre una terminal en esta carpeta y ejecuta:
     npm install
     npx cap add android
     npx cap sync android
     npx cap open android

2) En Android Studio espera a que termine "Gradle sync" y luego:
     Build > Build Bundle(s) / APK(s) > Build APK(s)

3) El APK queda en:
     android/app/build/outputs/apk/debug/app-debug.apk
   Pasalo al celular (WhatsApp, cable o Drive) e instalalo.
   Si el celular lo bloquea, permite "instalar apps de origen desconocido".

Para cambiar la app despues, edita www/index.html y repite: npx cap sync android
